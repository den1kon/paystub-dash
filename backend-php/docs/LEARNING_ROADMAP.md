- [ ] Create custom autoloader (PSR-4?)

- [ ] Use built-in web server
- [ ] Figure out `xdebug`
- [ ] Use `PDO`
- [ ] Start with `PHPDoc`
- [ ] Use `PHPStan` and `PHP_Codesniffer`
- [ ] Use SQLite for getting started ASAP
- [ ] Manual `.env` parser (Hardcode if tedious)
